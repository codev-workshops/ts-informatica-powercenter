# Agent notes

## Repo layout
- `XML/` — Informatica PowerCenter (9.6.1, repository version 187.96) PowerMart
  XML exports; files have no extension. Each is `<POWERMART> → REPOSITORY →
  FOLDER → SOURCE/TARGET/MAPPING/MAPPLET/WORKFLOW`.
- The `CPM`, `CPM_AFPS`, `CPM_CDC`, `CPM_NIH`, `CPM_OIG`, `FDA_Leave` files are
  partial exports of the same `CPM` folder; the root-level `Pseudossn` file is a
  byte-identical duplicate of `XML/Pseudossn`.
- Databases: Oracle (`ORA_BIIS`, `ORA_BIISPRD_SRC`), Flat File, VSAM, and
  PWX_SEQ_NRDB2 (PowerExchange mainframe datasets) endpoints.

## Generated docs — do not hand-edit
- `POWERCENTER_INVENTORY.md` and `POWERCENTER_LINEAGE.md` are generated by:
  `python3 scripts/powercenter_extract.py`  (stdlib only)
- Regenerate after any change to the XML exports and commit the result with the
  export changes.

## Shell scripts
- ksh scripts in `Transfer Scripts/` / `Maintenance Scripts/` and repo root use
  `mailx` notifications and `sftp` drops; workflows are ONDEMAND (external
  cron/manual orchestration).
