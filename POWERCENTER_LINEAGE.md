- **Targets**: `PSEUDOSSN_TBL` — Oracle; `ERROR_TBL` — Oracle

```
   Source Definition  PSEUDOSSN_FILE
    Source Qualifier  SQ_PSEUDOSSN_FILE <- PSEUDOSSN_FILE
          Expression  exp_Determine_Record_Type <- SQ_PSEUDOSSN_FILE
              Filter  fil_Detail_Records <- exp_Determine_Record_Type
              Sorter  srt_PSEUDOSSN_EFF_DT <- fil_Detail_Records
          Expression  exp_Determine_Errors <- srt_PSEUDOSSN_EFF_DT
              Router  rtr_Good_Bad_Records <- exp_Determine_Errors
          Expression  exp_Conversions <- rtr_Good_Bad_Records
          Normalizer  nrm_Errors <- rtr_Good_Bad_Records
    Lookup Procedure  lkp_Current_Pay_Period <- exp_Conversions
              Filter  fil_Error_Message <- nrm_Errors
          Expression  exp_Final <- exp_Conversions|lkp_Current_Pay_Period
          Expression  exp_Pay_Period <- fil_Error_Message
   Target Definition  PSEUDOSSN_TBL <- exp_Final
    Lookup Procedure  lkp_Current_Pay_Period1 <- exp_Pay_Period
          Expression  exp_Final_Errors <- exp_Pay_Period|lkp_Current_Pay_Period1
   Target Definition  ERROR_TBL <- exp_Final_Errors
```

### `m_Pseudossn_Verify_Record_Count` — 12 nodes (2 src / 1 tgt)

This mapping compares the total in the Trailer Record to the count of all Detail Records in the file.

- **Sources**: `PSEUDOSSN_FILE` — Flat File, FlatFile; `PSEUDOSSN_FILE1` — Flat File, FlatFile
- **Targets**: `PSEUDO_RECORD_COUNT` — Oracle

```
   Source Definition  PSEUDOSSN_FILE
   Source Definition  PSEUDOSSN_FILE1
    Source Qualifier  SQ_PSEUDOSSN_FILE <- PSEUDOSSN_FILE
    Source Qualifier  SQ_PSEUDOSSN_FILE1 <- PSEUDOSSN_FILE1
          Expression  exp_DETERMINE_HEADER_TRAILER <- SQ_PSEUDOSSN_FILE
          Expression  exp_DETERMINE_DETAIL <- SQ_PSEUDOSSN_FILE1
              Filter  fil_TRAILER <- exp_DETERMINE_HEADER_TRAILER
              Filter  fil_DETAIL <- exp_DETERMINE_DETAIL
          Aggregator  agg_ALL_RECORDS <- fil_DETAIL
              Joiner  jnr_RECORD_CONSTANTS <- fil_TRAILER|agg_ALL_RECORDS
          Expression  exp_COMPARE <- jnr_RECORD_CONSTANTS
   Target Definition  PSEUDO_RECORD_COUNT <- exp_COMPARE
```

### `m_Pseudossn_Counters` — 16 nodes (1 src / 2 tgt)

This mapping gets different counts on the PseudoSSN file that was processed and loads them to the Counters Table. 

- **Sources**: `PSEUDOSSN_FILE` — Flat File, FlatFile
- **Targets**: `COUNTER_TBL` — Oracle; `PSEUDOSSN_MESSAGE_FILE` — Flat File

```
   Source Definition  PSEUDOSSN_FILE
    Source Qualifier  SQ_PSEUDOSSN_FILE <- PSEUDOSSN_FILE
          Expression  exp_Determine_Detail <- SQ_PSEUDOSSN_FILE
              Filter  fil_Detail <- exp_Determine_Detail
          Aggregator  agg_ALL_RECORDS <- fil_Detail
          Expression  exp_Detail_Count <- agg_ALL_RECORDS
    Lookup Procedure  lkp_PSEUDOSSN_TBL_Pay_Period <- exp_Detail_Count
    Lookup Procedure  lkp_Count_PSEUDOSSN_Duplicates_ERROR_TABLE <- exp_Detail_Count
    Lookup Procedure  lkp_Count_PSEUDOSSN_TBL <- exp_Detail_Count
          Expression  exp_Counters <- exp_Detail_Count|lkp_PSEUDOSSN_TBL_Pay_Period|lkp_Count_PSEUDOSSN_Duplicates_ERROR_TABLE|lkp_Count_PSEUDOSSN_TBL
          Expression  exp_Build_Message <- exp_Counters
          Normalizer  nrm_Counters <- exp_Counters
          Expression  exp_Final_Message <- exp_Build_Message
          Expression  exp_Final <- nrm_Counters
   Target Definition  PSEUDOSSN_MESSAGE_FILE <- exp_Final_Message
   Target Definition  COUNTER_TBL <- exp_Final
```

### `m_Pseudossn_Verify_Header_Date_Current_Pay_Period` — 9 nodes (1 src / 1 tgt)

This mapping will verify that the Header Date in the PseudoSSN file matches the end date for the Current Pay Period.

- **Sources**: `PSEUDOSSN_FILE` — Flat File, FlatFile
- **Targets**: `PSEUDO_HDR_DATE_FILE` — Flat File

```
   Source Definition  PSEUDOSSN_FILE
    Source Qualifier  SQ_PSEUDOSSN_FILE <- PSEUDOSSN_FILE
          Expression  exp_Initial <- SQ_PSEUDOSSN_FILE
    Lookup Procedure  lkp_Current_Pay_Period <- exp_Initial
    Lookup Procedure  lkp_Pay_Period_Header_Date <- exp_Initial
          Expression  exp_Verify_Header_Date <- exp_Initial|lkp_Current_Pay_Period|lkp_Pay_Period_Header_Date
              Filter  fil_Header <- exp_Verify_Header_Date
          Expression  exp_Final <- fil_Header
   Target Definition  PSEUDO_HDR_DATE_FILE <- exp_Final
```
